  <p>You are ARNOLD, an android waking up in a lab. A voice asks how you're feeling. Answer normally and you pass. Ask the wrong question and Teddy, the engineer who built you, decides you need "a few more adjustments." The game even overrides you if you try to refuse to start. Every choice is written in Ink and runs inside Godot.</p>
</Chapter>

<Chapter n="02 · Design" title="Writing" light="a machine's first day">
  <ul>
    <li>Wrote the branching script in Ink: state flags track whether Arnold stays silent, cheers, or chills, and the dialogue reacts</li>
    <li>Built the terminal-style interface in Godot: speaker-colored lines (Arnold green, Teddy red), choice buttons, save/load and start over</li>
    <li>Integrated a playable pixel-art lab so the story can hand control to the player, then take it back</li>
  </ul>
