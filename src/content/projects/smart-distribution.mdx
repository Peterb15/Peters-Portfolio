<Chapter n="01 · System" title="Water," light="from a browser">
  <p>A distribution network built around four principles: track how much water is available, control where it goes (drinking or other outputs), adjust it all from a distance, and stay modular so it plugs into the class's storage, collection and treatment projects. An ESP32 hosts a live website. Solenoid gates open and close the lines, pumps sit inside each bucket, and inline flow sensors count every rotation to measure what moves.</p>
  <Clip src="/video/smart-distribution.mp4" poster={hero} ratio="9/16" maxWidth="420px" caption="The system running" />
  <ul>
    <li>Collaborated on the system architecture and the modular piping paths</li>
    <li>Built and wired the ESP32 control unit and the Ethernet relay setup</li>
    <li>Coded the onboard web server for remote valve and pump control</li>
    <li>Helped fabricate and assemble the physical system</li>
  </ul>
</Chapter>
